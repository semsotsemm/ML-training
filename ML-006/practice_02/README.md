# Загрязнение TCE · тренировочный вариант № 2

Три промышленных источника загрязняли водоносный горизонт. Скважины чаще встречаются рядом с промышленной зоной, а на больших глубинах и между зонами наблюдений меньше. Загрязнение переносится по неоднородным породам. Заречный водозабор смешивает воду из трёх эксплуатационных скважин.

## Задание

1. Для каждой строки `queries_test.csv` спрогнозируй концентрацию TCE в мкг/л и построй 90%-й интервал для концентрации в этой точке. Лабораторный шум измерений не входит в целевую величину. Запросы включают новые точки в 2022–2025 годах и прогноз на 2026–2028 годы.
2. Оцени массу **растворённого** TCE в водоносном горизонте на начало 1 января 2026 года. Границы, шаг расчётной сетки, толщина слоёв и эффективная пористость заданы в `domain.json`. Для центра каждой ячейки предскажи концентрацию, умножь её на объём воды в ячейке и просуммируй по сетке. При концентрации в мкг/л и объёме воды в м³ произведение выражено в миллиграммах. Раздели итог на 1 000 000, чтобы получить килограммы.
3. Найди первую дату **строгого превышения** 5 мкг/л на Заречном водозаборе с 1 января 2026 по 31 декабря 2028 включительно. Для каждого календарного дня концентрация на водозаборе равна `sum(Q_i * C_i) / sum(Q_i)` по скважинам с `role=intake`. `Q_i` — расход из `pumping.csv` на соответствующий месяц, `C_i` — концентрация в координатах и на глубине скважины. Если превышения в этот период нет, укажи `null`.

## Исходные данные

| Файл | Что в нём |
| --- | --- |
| `wells.csv` | 262 скважины и точки отбора. `x`, `y` в метрах, `z` — отметка в метрах относительно поверхности (`z = 0`). `role` обозначает назначение скважины. |
| `concentration.csv` | 3 731 лабораторная запись за 2020–2025 годы. `ND` и значения вида `<0.05` обозначают концентрацию ниже предела `lod_ug_l`. `quality` принимает значения `ok`, `replicate`, `rejected`. В журнале есть дубли. |
| `head.csv` | 2 453 наблюдения гидравлического напора в метрах. По пространственному градиенту можно оценить направление потока. |
| `cores.csv` | Литология слоёв у скважин. `z_top` выше `z_bottom`. |
| `permeability.tif` | Карта горизонтальной гидравлической проводимости верхнего слоя в м/сут. Размер 60 строк на 80 столбцов. Центр первого пикселя в точке `(25, 25)`. С номером строки растёт `y`, с номером столбца растёт `x`. Шаг 50 м, `-9999` означает отсутствие значения. |
| `pumping.csv` | Помесячный водоотбор для пяти скважин. Есть м³/сут и л/с. 1 л/с = 86,4 м³/сут. Указанный расход действует весь календарный месяц. |
| `abstraction.csv` | Суммарный помесячный водоотбор трёх скважин Заречного водозабора и координаты центра водозабора. |
| `recharge.csv` | Инфильтрационное питание в мм за месяц. Границы зон по `x`: `Industrial_Zone` до 1200 м, `Central_Zone` от 1200 до 2800 м, `Water_Intake_Zone` от 2800 м. |
| `sources.csv` | Положение трёх известных источников, периоды активности и ориентировочные скорости поступления TCE в г/сут. Пустой `end_date` означает действующий источник. |
| `queries_test.csv` | 960 запросов `query_id, x, y, z, t`. |
| `domain.json` | Расчётная область `[0, 4000] × [0, 3000]` м, три слоя, пористость и параметры расчёта. |

В журналах встречаются даты `YYYY-MM-DD` и `DD.MM.YYYY`. Данные водоотбора и инфильтрации до конца 2028 года доступны как заданный сценарий прогноза. Концентрации, напоры и остальные входные данные связаны одной упрощённой синтетической моделью потока и переноса. Концентрации зависят от поступления из источников, движения воды, рассеяния, перехода между слоями, распада и откачки. На лабораторных пробах отдельно моделируются погрешность измерений и предел обнаружения. Физические процессы описаны в [руководстве USGS по переносу в подземных водах](https://pubs.usgs.gov/publication/tm6A61).

## Формат и проверка

Подготовь папку `submission` с двумя файлами.

- `predictions.csv` с колонками `query_id,prediction,lower_90,upper_90`. Ровно одна строка на запрос, значения в мкг/л, `0 <= lower_90 <= prediction <= upper_90`.
- `summary.json` с полями `mass_kg` (число) и `arrival_date` (строка `YYYY-MM-DD` или `null`).

Из этой папки с заданием запусти следующие команды в Python с установленными NumPy, pandas и SciPy. Для чтения TIFF в своём решении можешь использовать `tifffile`.

```powershell
python baseline.py --output submission_baseline
python scorer.py submission_baseline
python scorer.py submission
```

`baseline.py` усредняет ближайшие наблюдения с весами по пространству, глубине и времени. Оценщик проверяет RMSE и MAE, фактическое покрытие 90%-х интервалов, их среднюю ширину и интервальный балл (меньше лучше). Исторические и будущие запросы проверяются также по отдельности. Для массы выводятся абсолютная и относительная ошибки, для водозабора — правильность факта превышения и ошибка даты в днях, если обе даты заданы.

Скрытый ключ лежит в `_scoring` и нужен `scorer.py`. Для самостоятельной тренировки открывай результаты проверки после того, как сформируешь прогноз. Для выбора модели заранее зафиксируй собственные разбиения по времени и скважинам.
