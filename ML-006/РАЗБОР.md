# Почему RMSE высокий в первом задании

Медиана в `encoded-train.parquet` равна 3,54 мкг/л, среднее — 174,55, 95-й процентиль — 929,22, максимум — 3007,95. В чистых тестовых ответах медиана 13,56 и 95-й процентиль 391,01. Концентрации асимметричны, а тренировочные скважины и запросы расположены по-разному. Одно значение медианы плохо описывает любой из этих наборов.

RMSE — корень из среднего квадрата ошибок. Если в 99 точках ошибка равна 3, а в одной 1000, общий RMSE равен примерно 100, хотя медиана абсолютной ошибки равна 3. На старом чистом тесте прогноз константой из медианы очищенного обучения даёт RMSE **164,13**. Смотри на MAE вместе с RMSE и отдельно проверяй, какие точки вносят наибольший вклад в сумму квадратов.

В старом генераторе истинная концентрация складывается из двух пятен. Одно остаётся у источника, второе движется и расширяется. Истинное поле в `data_generator.py` вычисляется по `x, y, z, t`. Напор, породы, откачка и другие таблицы создаются отдельно и напрямую в эту формулу не входят. Поэтому добавление всех колонок само по себе не восстановит движение пятна. В новом варианте эти процессы связаны.

## Как устроено улучшение

Запуск из корня проекта в текущем окружении.

```powershell
.venv/Scripts/python.exe ML-006/improve_tce.py --score --output predictions_tce.csv
```

1. `load_observations` читает исходные CSV, приводит даты к одному отсчёту, обрабатывает предел обнаружения, удаляет повторы и внесённый старым генератором маркер `999.99`.
2. `predict` складывает два плавных пятна и малый фон. Оно сначала переводит `x, y` в координаты вдоль и поперёк потока. Затем смещает центр подвижного пятна на `speed * days`. Значение каждого пятна уменьшается с расстоянием до его центра, с разным масштабом по трём осям.
3. `fit` подбирает скорость, направление, ширину, глубину и амплитуды по замерам. Для старых данных форма взята из генератора. Численные параметры подбираются заново. `log1p` уменьшает влияние мультипликативного лабораторного шума, а робастная функция `soft_l1` смягчает влияние отдельных выбросов. RMSE при проверке вычисляется в мкг/л. [Документация SciPy по least_squares](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html)
4. `validate` проверяет перенос на отложенные пространственные блоки и отдельно на 2025 год. Для финального прогноза модель обучается на всех очищенных измерениях. `predict_clean` использует правило именно этого генератора: к чистому полю прибавляется 0,10 мкг/л, результат округляется до двух знаков. С флагом `--score` чистые ответы читаются после записи прогноза.
5. `bootstrap_predictions` повторно обучает модель на выборках пространственных блоков. Процентили предсказаний показывают, насколько форма пятна меняется от состава обучающей выборки. На этом тесте интервалы получились консервативными: 97,7% покрытия при цели 90%.

| Проверка | Результат |
| --- | ---: |
| XGBoost в последней ячейке ноутбука, чистые запросы | 34,27 RMSE в сохранённом выводе, 32,65 при повторном запуске |
| Два пятна с обучаемыми параметрами, чистые запросы | **7,43 RMSE**, 3,34 MAE |
| Два пятна, шумные замеры отложенных пространственных блоков | 63,23 RMSE |
| Два пятна, шумные замеры за 2025 год | 103,76 RMSE |
| Покрытие интервалов на чистых запросах | 97,7% |

В разбиении по времени верхние 10% концентраций дают 86,3% суммы квадратов ошибок. По коду старого генератора крупные концентрации умножаются на случайный фактор. Для сравнения я подставил в эту проверку точное поле старого генератора: против тех же шумных замеров 2025 года оно дало около 100 RMSE. Число 24 в сохранённых выводах не обнаружилось. Его можно сравнить, когда известно, на каких ответах и каком разбиении оно рассчитано.

## Какие алгоритмы попробовать на втором наборе

| Алгоритм | Когда пробовать | Первый эксперимент |
| --- | --- | --- |
| Медиана или среднее | Первая точка отсчёта. Среднее минимизирует MSE среди констант на фиксированной выборке, медиана минимизирует MAE. | Посчитай оба на обучении, проверь RMSE и MAE на одном отложенном периоде. |
| KNN или IDW | Вблизи есть пробы, соседние точки похожи. | Подбери отдельные масштабы метров по горизонтали, метров по глубине и дней. Измерь качество отдельно на ближних и дальних запросах. |
| Градиентный бустинг по деревьям | Есть нелинейные связи и признаки, которые можно построить и для обучения, и для запросов. | Начни с `HistGradientBoostingRegressor` или `XGBRegressor`. Добавь расстояние до источников, проводимость под точкой и положение относительно направления потока. Проверяй будущий год: деревья по времени плохо продолжают тренд за пределами обучения. |
| Пространственная регрессия с гладкой функцией | Можно сформулировать, где поле меняется плавно и как движется загрязнение. | Попробуй сгладить координаты по направлению потока или добавить к интерполяции тренд перемещения. Два пятна из первого задания были одной конкретной гипотезой. |
| Квантильная регрессия или интервалы по ошибкам валидации | Для 90%-х интервалов важно проверить разные глубины, годы и плотность скважин. | Сравни покрытие и ширину на отложенных блоках и будущем периоде. Подбор интервала по одному режиму может дать другое покрытие в другом режиме. |

## План на неделю

- **День 1.** Запусти `improve_tce.py`. Вручную посчитай RMSE для трёх прогнозов, затем разберись, откуда берутся `along`, `across` и `speed * days`.
- **Дни 2–3.** На новом наборе сам собери таблицу скважин и замеров, зафиксируй разбиения по времени и по блокам. Реализуй свою базовую модель и сравни её с бустингом. Веди короткую таблицу «изменение / RMSE / MAE» и меняй по одной вещи за запуск.
- **День 4.** Добавь интервалы, интеграл массы и кривую концентрации водозабора. Проверь оба файла через `scorer.py`.
- **Дни 5–6.** Переключись на трамваи. Начни с короткого запуска среды и проверь полный путь от `reset(tram_id)` и `act(tram_id, obs)` до сохранения и загрузки TorchScript. Затем сравни политику на нескольких сидах.
- **День 7.** С нуля воспроизведи одну сдачу по каждому заданию. После каждого запуска своими словами объясни, какие данные идут на вход, как проверяешь прогноз и где модель ошибается. Сверяйся с кодом после объяснения.
