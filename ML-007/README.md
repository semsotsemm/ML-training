# ML-007 · Подготовка пространственно-временных данных

Ты получил журнал лабораторных замеров, таблицу скважин, карту пород и список запросов. Подготовь из них таблицы для обучения и прогноза концентрации TCE.

- [practice.ipynb](practice.ipynb) содержит восемь заданий с подсказками и проверками.
- [СПРАВОЧНИК.md](СПРАВОЧНИК.md) содержит короткие рецепты pandas, NumPy и scikit-learn. Начни с разделов про фильтры, пропуски, даты и объединение таблиц.

## Запуск

Открой `practice.ipynb` в Jupyter или IDE и выбери ядро Python из `.venv` проекта. Для запуска Jupyter из корня проекта подойдёт:

```powershell
.venv/Scripts/python.exe -m jupyter notebook ML-007/practice.ipynb
```

Ноутбук читает исходные данные из соседней папки `ML-006/practice_02`. В ней уже есть CSV, TIFF и описание формата. Для упражнений нужны pandas, NumPy, scikit-learn и tifffile. Ячейки с проверками подскажут, какие переменные или функции ещё нужно написать.

## Что должно получиться

1. Очищенные замеры с одной строкой на скважину и дату.
2. Таблица с координатами, породой на глубине пробы и ближайшим прошлым замером напора. Это материал для аудита данных.
3. Три таблицы признаков одной структуры. Обучение включает наблюдения до 2025 года, валидация — 2025 год, третья таблица — точки из `queries_test.csv`. Признаки вычисляются общей функцией по доступным на входе координатам и дате.
4. Препроцессор scikit-learn, который учит заполнение пропусков, масштабирование и словарь категорий на обучающей таблице. Применить его нужно ко всем трём таблицам.

Пройди первые четыре задания за один подход. Затем попробуй восстановить очистку замеров в пустой ячейке по памяти. Если забудешь синтаксис, загляни в справочник и продолжай. На следующем подходе сделай то же с чтением TIFF и `fit` / `transform`.
