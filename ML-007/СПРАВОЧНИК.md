# Справочник по препроцессингу

`df` — таблица `DataFrame`, `df["x"]` — одна колонка `Series`, `df[["x", "y"]]` — таблица из двух колонок. `a` — массив NumPy. В примерах `pd` и `np` означают `import pandas as pd` и `import numpy as np`. Начни с первого подходящего рецепта и проверь его на трёх строках.

## 1. Чтение и первое знакомство с таблицей

| Что нужно | Что написать |
| --- | --- |
| CSV с ID, где важны нули слева | `pd.read_csv(path, dtype={"well_id": "string"})` |
| CSV с разделителем `;` и десятичной запятой | `pd.read_csv(path, sep=";", decimal=",")` |
| Прочитать часть колонок или строк | `pd.read_csv(path, usecols=["x", "y"], nrows=100)` |
| Parquet с сохранёнными типами | `pd.read_parquet(path)` |
| Число строк и столбцов, имена и типы | `df.shape`, `df.columns`, `df.dtypes`, `df.info()` |
| Посмотреть начало, конец или случайные строки | `df.head(5)`, `df.tail(5)`, `df.sample(5, random_state=42)` |
| Статистики и квантили | `df.describe()`, `df["c"].quantile([0.5, 0.95, 0.99])` |
| Частоты и число разных значений | `df["quality"].value_counts(dropna=False)`, `df["well_id"].nunique()` |
| Пропуски и дубли по ключу | `df.isna().sum()`, `df.duplicated(["well_id", "t"], keep=False).sum()` |
| Записать таблицу | `df.to_csv(path, index=False)`, `df.to_parquet(path, index=False)` |

Сразу проверь единицы измерения, диапазоны дат и уникальность ключей. `shape` и `dtypes` — свойства без скобок, `head()` и `info()` — методы.

## 2. Индексы, фильтры и присваивание

| Задача | Синтаксис |
| --- | --- |
| Выбрать колонки по имени | `df[["x", "y"]]` |
| Выбрать первые три строки и два столбца по позициям | `df.iloc[:3, :2]` |
| Выбрать строки маской и конкретные колонки | `df.loc[df["x"] > 0, ["x", "z"]]` |
| Исправить знак только у положительных глубин | `df.loc[df["z"] > 0, "z"] = -df["z"]` |
| Условия «и», «или», «нет» | `(df["z"] < -20) & (df["x"] > 1000)`, `a \| b`, `~a` для булевых масок |
| Попадает в диапазон | `df["z"].between(-76, 0)` |
| Попадает в список | `df["quality"].isin(["ok", "replicate"])` |
| Поменять имена, порядок и индекс | `df.rename(columns={"head": "head_m"})`, `df.sort_values(["well_id", "t"])`, `df.reset_index(drop=True)` |
| Удалить колонку | `df.drop(columns=["unused"])` |
| Добавить колонки без изменения исходной таблицы | `df.assign(depth_m=-df["z"])` |

`~` инвертирует булеву маску: `True` становится `False`. Минус перед числом меняет знак. Сравнения перед `&` и `|` заключай в скобки. Для присваивания используй один вызов `.loc[строки, колонка]`. `.loc` работает с метками, `.iloc` — с позициями. При присваивании `Series` pandas сопоставляет значения по меткам индекса.

```python
keep = df["quality"].isin(["ok", "replicate"])
rejected = df.loc[~keep]
clean = df.loc[keep].copy()
```

[Выбор и индексация в pandas](https://pandas.pydata.org/docs/user_guide/indexing.html)

## 3. Строки, числа, пропуски и выбросы

| Задача | Синтаксис |
| --- | --- |
| Привести строки к общему виду | `s.astype("string").str.strip().str.lower()` |
| Найти префикс или текст | `s.str.startswith("<", na=False)`, `s.str.contains("error", case=False, na=False, regex=False)` |
| Достать число из строки вида `<0.05` | `s.str.extract(r"^<\s*([\d.]+)$", expand=False)` |
| Числа из строк, ошибки становятся пропусками | `pd.to_numeric(s, errors="coerce")` |
| Проверить, заполнить или убрать пропуски | `s.isna()`, `s.notna()`, `s.fillna(0)`, `df.dropna(subset=["x", "y"])` |
| Заменить технический маркер | `s.replace(-9999, np.nan)` |
| Заменить там, где условие истинно | `s.mask(s < 0)` |
| Сохранить там, где условие истинно | `s.where(s >= 0)` |
| Выбрать два значения по условию | `np.where(keep, 1, 0)` |
| Удалить одинаковые строки или дубли по ключу | `df.drop_duplicates()`, `df.drop_duplicates(["well_id", "t"], keep="last")` |
| Проверить NaN и бесконечности числового массива | `np.isfinite(a)` |
| Ограничить по заданным границам | `s.clip(lower=0, upper=1000)` |
| Применить словарь значений | `s.map({"m3/day": 1.0, "l/s": 86.4})` |
| Заменить фрагмент строки | `s.str.replace(",", ".", regex=False)` перед числовым парсингом, если запятая отделяет дробную часть |
| Целые числа с пропусками | `s.astype("Int64")` после проверки, что значения целые |

`ND` и `<0.05` в журнале означают измерение ниже предела обнаружения. Для простого учебного варианта возьми половину предела и заведи флаг `censored`. Высокий результат может быть настоящим пиком. Сначала проверь единицы, метку качества и повторные измерения. Если границу выброса определяешь по квантилям, считай их на обучении.

## 4. Даты и временные признаки

```python
iso = pd.to_datetime(s, format="%Y-%m-%d", errors="coerce")
european = pd.to_datetime(s, format="%d.%m.%Y", errors="coerce")
t = iso.fillna(european)
days = (t - pd.Timestamp("2020-01-01")).dt.days
```

Явные форматы сохраняют смысл двусмысленных дат. Например, ISO `2025-02-03` и `03.02.2025` — один и тот же день. Проверь число пропусков после разбора.

| Задача | Синтаксис |
| --- | --- |
| Год, месяц, день недели | `t.dt.year`, `t.dt.month`, `t.dt.dayofweek` |
| Округлить время до начала дня | `t.dt.normalize()` |
| Начало календарного месяца | `t.dt.to_period("M").dt.to_timestamp()` |
| Интервал времени | `pd.Timedelta(days=60)` |
| Последовательность дат | `pd.date_range("2025-01-01", periods=12, freq="MS")` |
| Временное разбиение | `train = df.loc[df["t"] < cutoff]`, `val = df.loc[df["t"] >= cutoff]` |
| Циклический признак месяца | `phase = 2 * np.pi * (t.dt.month - 1) / 12`, затем `np.sin(phase)` и `np.cos(phase)` |
| Сдвиг на одно предыдущее наблюдение в группе | `df.sort_values("t").groupby("well_id")["value"].shift(1)` |
| Окно из предыдущих наблюдений | `df.sort_values("t").groupby("well_id")["value"].transform(lambda s: s.shift(1).rolling(3, min_periods=1).mean())` |
| Последнее известное значение в группе | `df.sort_values("t").groupby("well_id")["value"].ffill()` |

Если используешь исторические концентрации как признаки, сначала проверь, какие измерения будут доступны на дату прогноза. Проверь это отдельно для новых координат без `well_id`.

## 5. Объединение, группировки и преобразование формы

| Задача | Синтаксис |
| --- | --- |
| Подтянуть одну скважину к каждой пробе | `samples.merge(wells, on="well_id", how="left", validate="many_to_one", indicator=True)` |
| Склеить таблицы вертикально | `pd.concat([part1, part2], ignore_index=True)` |
| Одна строка на группу | `df.groupby(["well_id", "t"], as_index=False).agg(c=("c", "median"), n=("c", "size"))` |
| Статистика группы в каждой исходной строке | `df.groupby("well_id")["c"].transform("median")` |
| Размер группы или число непустых значений | `g.size()`, `g["c"].count()` для `g = df.groupby("well_id")` |
| Широкая таблица из уникальных пар | `df.pivot(index="t", columns="well_id", values="rate")` |
| Широкая таблица с агрегацией повторов | `df.pivot_table(index="t", columns="well_id", values="rate", aggfunc="mean")` |
| Широкая таблица в длинную | `df.melt(id_vars=["t"], var_name="well_id", value_name="rate")` |
| Разбить числа на заданные интервалы | `pd.cut(z, [-np.inf, -46, -20, np.inf], labels=["deep", "middle", "shallow"])` |
| Разбить по квантилям | `pd.qcut(s, q=4, duplicates="drop")` |

После `merge` сравни число строк до и после, а при `indicator=True` посмотри частоты `_merge`. Один ключ с повторами с обеих сторон может размножить строки. Проверь пропуски в ключах: pandas может сопоставить два отсутствующих ключа.

Ближайший **прошлый** замер напора той же скважины:

```python
joined = pd.merge_asof(
    samples.sort_values("t"),
    head.sort_values("head_t"),
    left_on="t", right_on="head_t", by="well_id",
    direction="backward",
    tolerance=pd.Timedelta(days=180),
)
```

`backward` ищет запись с датой меньше или равной дате пробы. Если нужен строго прошлый замер, добавь `allow_exact_matches=False`. Обе таблицы сортируй по временному ключу. [Документация pandas по merge_asof](https://pandas.pydata.org/docs/reference/api/pandas.merge_asof.html)

## 6. NumPy, координаты и TIFF

| Задача | Синтаксис |
| --- | --- |
| Из Series или таблицы в массив | `df[["x", "y"]].to_numpy(dtype=float)` |
| Размер и число осей массива | `a.shape`, `a.ndim`, `a.size` |
| Развернуть матрицу в один ряд значений | `a.ravel()` |
| Изменить форму, сохранив число элементов | `a.reshape(-1, 2)` |
| Соединить векторы в столбцы | `np.column_stack([x, y])` |
| Сложить массивы новой осью или по существующей оси | `np.stack([a, b], axis=0)`, `np.concatenate([a, b], axis=0)` |
| Среднее по всем значениям, по колонкам, по строкам | `a.mean()`, `a.mean(axis=0)`, `a.mean(axis=1)` |
| Статистики, игнорирующие NaN | `np.nanmean(a)`, `np.nanmedian(a)`, `np.nanquantile(a, 0.95)` |
| Евклидово расстояние в плоскости | `np.hypot(x - x0, y - y0)` |
| Индексы ячейки с округлением вниз | `np.floor((x - x_min) / step).astype(int)` для конечных координат |
| Логарифм для неотрицательных величин и обратный ход | `np.log1p(c)`, `np.expm1(log_c)` |

Для TIFF обращение идёт как `raster[строка, столбец]`. В нашем наборе строка растёт по `y`, столбец по `x`. Направление осей и шаг всегда бери из описания конкретного растра. `raster.shape[0]` — количество строк, `raster.shape[1]` — столбцов.

```python
raster = np.array([[10, 11, 12], [20, 21, 22]])
row, col = np.mgrid[0:raster.shape[0], 0:raster.shape[1]]
print(row)  # [[0, 0, 0], [1, 1, 1]]
print(col)  # [[0, 1, 2], [0, 1, 2]]

points = np.column_stack([col.ravel(), row.ravel(), raster.ravel()])
# Первая строка points — x-индекс 0, y-индекс 0, значение 10.
x_centers = x_min + (col + 0.5) * step
y_centers = y_min + (row + 0.5) * step
```

`mgrid` полезен, когда нужны координаты **всех** ячеек, например для интеграла массы. Когда нужны значения только в точках запроса, вычисли для каждой точки пару индексов и возьми `raster[row, col]`. Сначала проверь границы и `NoData`: отрицательный индекс NumPy берёт элемент с конца. Для считывания подойдут `tifffile.imread(path)` и метаданные набора. [Документация NumPy по mgrid](https://numpy.org/doc/stable/reference/generated/numpy.mgrid.html)

## 7. Масштабирование, кодирование и Pipeline

| Метод | Когда попробовать |
| --- | --- |
| `SimpleImputer(strategy="median")` | Числовой признак иногда отсутствует. Медиану оцениваем по обучению. |
| `SimpleImputer(strategy="median", add_indicator=True)` | Хочешь передать модели, какие числовые значения были пропущены. |
| `SimpleImputer(strategy="most_frequent")` | Для категорий нужен способ заполнения пропусков. Можно также использовать отдельную категорию. |
| `StandardScaler()` | KNN, линейные модели с регуляризацией, многие нейросети. Вычитает среднее и делит на стандартное отклонение каждого признака. |
| `RobustScaler()` | Есть выбросы. По умолчанию использует медиану и межквартильный размах. |
| `MinMaxScaler()` | Нужен масштаб, например от 0 до 1 на обучении. Новое значение за пределами обучающего диапазона может выйти за 0–1. |
| `Normalizer(norm="l2")` | Нужна единичная длина каждой строки, например для вектора частот слов. Для координат скважин чаще нужно масштабирование по столбцам. |
| `OneHotEncoder(handle_unknown="ignore")` | Категории без естественного порядка, например порода. Незнакомая категория даёт нули в столбцах этого признака. |
| `OrdinalEncoder(handle_unknown="use_encoded_value", unknown_value=-1)` | Есть осмысленный порядок категорий. Передай его через `categories`. |
| `pd.get_dummies(df, columns=["zone"])` | Быстрый просмотр категорий. Для ML проще один обученный `OneHotEncoder`, который сам сохраняет набор выходных колонок. |
| `np.log1p(y)` | Эксперимент с асимметричной неотрицательной целью. После `np.expm1(pred)` посчитай RMSE в исходных единицах. |
| Деревья и бустинг по деревьям | Масштабирование чисел обычно можно пропустить. Чистка, правильные единицы и доступность признаков по-прежнему важны. |

Минимальный пример с несколькими типами колонок:

```python
from sklearn.compose import ColumnTransformer
from sklearn.impute import SimpleImputer
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import OneHotEncoder, StandardScaler

num = ["x", "y", "z", "days"]
cat = ["zone"]
prep = ColumnTransformer([
    ("num", make_pipeline(SimpleImputer(strategy="median"), StandardScaler()), num),
    ("cat", OneHotEncoder(handle_unknown="ignore", sparse_output=False), cat),
])
X_train_ready = prep.fit_transform(X_train)
X_val_ready = prep.transform(X_val)
X_test_ready = prep.transform(X_test)
columns = prep.get_feature_names_out()
```

`fit` запоминает параметры, `transform` применяет их, `fit_transform` выполняет оба шага. Для обучения модели можно использовать `make_pipeline(prep, model)`. Тогда при кросс-валидации весь pipeline обучается внутри каждого разбиения. [Препроцессинг scikit-learn](https://scikit-learn.org/stable/modules/preprocessing.html), [утечка данных](https://scikit-learn.org/stable/common_pitfalls.html)

## 8. Что проверить перед обучением

- Разбей данные по будущему времени или по группам скважин. Для пространственной проверки подойдут `GroupShuffleSplit` и `GroupKFold` с ID скважины или пространственным блоком в `groups`.
- Отдели `y`, ID и служебные колонки от `X`. Проверь `list(X_train.columns) == list(X_test.columns)` до преобразования.
- Проверь уникальность ключей через `assert df[key].is_unique` и число строк после каждого объединения.
- Проверь, сколько строк потеряно при чистке, сколько NaN осталось и какие категории встречаются только в валидации.
- Для числовой матрицы после препроцессинга проверь `np.isfinite(X_ready).all()`. У обучающего `StandardScaler` среднее преобразованного столбца близко к нулю. Среднее валидации может отличаться.
- Убедись, что для каждой точки теста строятся те же признаки и в тех же единицах. Удобно сделать одну функцию `make_features(points)` и вызвать её для обеих таблиц.
