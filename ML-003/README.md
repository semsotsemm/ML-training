Задача: В реальных задачах машинного обучения работа всегда начинается с первичного осмотра датасета. Данные редко бывают идеальными: в них часто встречаются пропущенные значения (NaN), а колонки имеют разные типы (числа, категории, неструктурированный текст), к каждому из которых нужен свой подход при предобработке.

Чтобы не зависеть от скачивания внешних файлов, мы будем использовать небольшой синтетический датасет. Загрузите его в свой Jupyter Notebook (или Python-скрипт) с помощью этого стартового кода:

``` Python
import pandas as pd
import io

csv_data = """id,name,age,department,salary,is_manager,notes
1,Иван,34,IT,150000.0,False,Отличный работник
2,Мария,,HR,120000.0,True,
3,Петр,28,IT,,False,В отпуске
4,Анна,45,Finance,200000.0,True,
5,Алексей,31,,130000.0,False,Испытательный срок"""

df = pd.read_csv(io.StringIO(csv_data))
```

**Что нужно сделать в коде:**

1. Выведите общую информацию о датасете (изучите метод `df.info()` или свойства `df.dtypes` и `df.isnull()`).
    
2. Напишите код, который вычисляет **долю строк** (от 0 до 1 или в процентах), содержащих хотя бы одно пропущенное значение.
    
3. Напишите код, который подсчитывает долю переменных (колонок) каждого типа:
    
    - численные (`int64`, `float64`),
        
    - логические/категориальные (`bool`),
        
    - текстовые (`object`).
