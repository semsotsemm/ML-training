# Тестирования сравнивание тензоров

## Задание

В PyTorch можно применять стандартные логические операторы (например, `==`, `<`, `>`) к тензорам одинаковой формы. Результатом такой операции будет новый тензор, состоящий из булевых значений (`True` или `False`), где каждый элемент является результатом сравнения соответствующих ячеек исходных матриц.

Рассмотрите следующий базовый код:
```Python
import torch

X = torch.arange(12, dtype=torch.float32).reshape((3, 4))
Y = torch.tensor([[2.0, 1, 4, 3], 
                  [1.0, 2, 3, 4], 
                  [4.0, 3, 2, 1]])
```

**Задание:**
1. Используя тензоры `X` и `Y` из кода выше, напишите команды для их логического сравнения: выясните, где элементы `X` строго меньше элементов `Y` (`X < Y`), и где элементы `X` строго больше (`X > Y`). 
2. Выведите результаты вычислений на экран.
3. Напишите (в комментариях к коду или текстом), тензор какого типа данных (dtype) возвращают эти операции, и объясните, как интерпретировать полученный результат.

## Комментарии к заданию
torch — это библиотека, с открытым исходным кодом, которая используется для создания, обучения, и развертывания глубоких нейронных сетей

arange(start= , end= , step= , dtype= ) — функция, которая создает одномерный тензор-вектор из последовательно возрастающих или убывающих чисел в заданном диапазоне. 
tensor(data= ) — функция для созданимя n-мерного тензора, в качестве аргумента передаем список.
При выполнении логических операций (>, >=, <, == и т.д.) оперпация выполняется над каждым отдельным числом тензора.
reshape — изменяет размерность тензора, в качестве аргумента принимает кортеж, где первый элемент — количество строк, второй — количество столбцов. 

В качестве одного из аргументов в обе функции можно передать device — параметр, который укажет где выполнять вычисления "cpu" — на процессоре или "cuda" — на видеокарте.
